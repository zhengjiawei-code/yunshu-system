## 0. 交互总览

- 左右分栏：左侧 208px 固定机构树（全量，含禁用），右侧平铺机构明细。
- 左树默认选中内置“总部”（`id=1`）；点击节点切换右侧数据范围。
- 右侧展示所选机构的**全部后代（含多级）**，平铺展示，用“上级机构”列表达层级；不包含所选机构自身。
- 顶部「新增机构」默认挂在当前选中机构下；行内不再提供“新增子机构”，新增子机构通过选中父节点后点“新增机构”完成。
- 抽屉 640px：基础信息（含“是否末端”）；机构授权走操作列的独立抽屉。
- 列表恢复标准能力：筛选、分页、合计、导出、列设置；**树形表例外取消**。
- 上级机构用树选择，只能选机构；不能选自身及后代。
- 类型由用户选择，默认值：上级是总部 → 公司，其他 → 部门；受父子矩阵约束。

## 2. 抽屉字段

### 2.1 基础信息抽屉

| # | 字段名 | label | 控件 | 必填 | 校验规则 | 默认值 | 编辑态 |
|---|---|---|---|---|---|---|---|
| 1 | parentId | 上级机构 | 树选择（仅机构） | **是** | 只能选启用机构；不能选自身及后代；满足父子矩阵；总深度 ≤5 | 当前选中机构 | 可改（受矩阵/环检测/深度限制） |
| 2 | deptType | 机构类型 | 下拉单选（5 类） | 是 | 1 总部 / 2 公司 / 3 部门 / 4 分拨中心 / 5 网点；总部不可选（仅内置）；必须满足“父→子”矩阵 | 上级是总部→公司；其他→部门 | 可改（需同时满足父与子两段矩阵） |
| 3 | deptNature | 机构性质 | 下拉单选（自营/加盟/合作） | **是** | 只能 1/2/3；总部固定自营（前端禁用、后端拒绝改成其它值） | 自营 | 可改（总部除外） |
| 3.1 | isLeaf | 是否末端 | 勾选框 | 否 | **仅当机构类型=网点时可勾选**；其它类型禁用置灰并自动清空；后端同样校验（非网点传 true 直接拒绝） | 不勾选 | 可改（仅网点） |
| 4 | deptName | 机构名称 | 输入框 | 是 | 2–50 字；去首尾空格；同一上级下唯一（排除自身） | 空 | 可改 |
| 5 | deptCode | 机构编码 | 输入框 | 是 | 2–20 位 `^[A-Za-z0-9_]{2,20}$`；全局唯一（deleted=0）；**创建后不可修改** | 空 | **只读** |
| 6 | leader | 负责人 | 输入框 | 否 | ≤20 字 | 空 | 可改 |
| 7 | phone | 联系电话 | 输入框 | 否 | ≤20 位；手机或座机 `^(1[3-9]\d{9}|0\d{2,3}-?\d{7,8})$` | 空 | 可改 |
| 8 | address | 机构地址 | 输入框（自动识别省/市/区县） | 否 | ≤200 字；输入防抖后自动识别并回填三级区划，可手改；识别失败/部分识别不阻断保存 | 空 | 可改 |
| 9 | sortOrder | 排序 | 数字输入 | 是 | 整数 0–9999 | 同级最大值 +10 | 可改 |
| 10 | status | 状态 | 开关：启用 / 禁用 | 是 | 总部不可禁用 | 启用 | 可改 |
| 11 | remark | 备注 | 文本域 | 否 | ≤500 字 | 空 | 可改 |

> `deptCode` 编辑态只读，避免对接与历史数据断链。
> `isLeaf` 是**业务标识**：表示该网点是否为末端网点，与结构上是否有下级无关（网点下挂部门后仍可为末端网点）；禁止在前端或后端把它当作结构叶子联动增删。

**地址自动识别（2026-11-21 固定规范条款）**

1. 只使用本地已导入的区划数据（省/市/区县三级），**不调用第三方在线服务**；接口 `POST /api/v1/system/regions/recognize-address`。
2. 匹配取**最长优先**：`吉林市` 不得误判为 `吉林省`；支持带/不带“省/市/区/县”后缀、直辖市写法（北京市/北京市市辖区/朝阳区）、自治区简称（内蒙古/广西/宁夏/新疆/西藏）、“市辖区”占位、县级市与地区名。
3. 同名区县按已识别出的上级消歧（如“杭州市西湖区”优于“南昌市西湖区”）；无法消歧时返回候选并提示“存在同名区县，请手动选择”，不阻断保存。
4. 交互：输入防抖 400ms，一次输入只发一次识别请求；最新请求结果才允许回填。识别成功回填省/市/区县三个下拉，用户仍可手动改；**只回填三级区划，不覆盖负责人、电话等用户已手动修改的其他字段**。
5. 识别失败或部分识别时提示“未能识别地区，请手动选择”，**不阻断保存**。
6. 校验口径不变：分拨中心、网点的省/市/区县必填；总部/公司/部门选填。机构地址仍为省/市/区县三级，不因外转/直达支持乡级而扩展机构表。

### 2.2 机构授权抽屉（操作列入口）

| # | 字段名 | label | 控件 | 默认 | 说明 |
|---|---|---|---|---|---|
| 11 | allowShip | 能否发货 | 开关 | 开 | 开启后该机构可作为发货机构开单；开单模块保存时校验 |
| 12 | allowArrival | 能否到货 | 开关 | 开 | 开启后该机构可作为到货机构；到货卸车模块校验 |
| 13 | allowPrepaidUnpaid | 现付未付开单 | 开关 | **关** | 开启后客户现付运费未结清也可开单；资金风险，默认关闭 |
| 14 | allowCollectUnpaidSign | 到付未付签收 | 开关 | **关** | 开启后到付运费未结清也可签收；资金风险，默认关闭 |

授权抽屉固定说明文案：

> 业务授权按机构独立生效，**不随父机构自动继承**；这里的开关控制“这个机构能不能做这类业务”，与角色的菜单/按钮功能权限是两回事，两者同时校验。

- 授权抽屉独立保存（底部「取消 / 保存」），入口在操作列「机构授权」；
- 基础信息保存不携带授权开关，后端保留原值，避免误重置；
- 抽屉分「业务能力」与「扩展授权」两个分区，后者为后续授权项预留。

## 3. 校验规则（后端最终口径）

| 规则 | 文案/行为 |
|---|---|
| 上级机构必填 | 「请选择上级机构」（总部除外，总部不可新建） |
| 上级只能是机构 | 「上级机构必须是机构节点」 |
| 不能选自身/后代 | 「上级机构不能是自己或自己的子机构」 |
| 层级上限 | 「机构层级最多 5 级，当前已超出」 |
| 父子类型矩阵 | 「{父类型}下不允许创建{子类型}」 |
| 上级必须启用 | 「上级机构已禁用，不能在其下新增机构」 |
| 总部唯一 | 「系统只允许一个总部，不能新增或移动总部」 |
| 名称同级唯一 | 「同一上级下已存在同名机构：xxx」 |
| 编码全局唯一 | 「机构编码已存在：xxx」 |
| 编码不可改 | 前端只读 + 后端拒绝修改 |
| 总部保护 | 不可删、不可禁用、不可移动、类型不可改 |
| 类型修改 | 同时满足“父→新类型”和“新类型→所有现有子类型”，否则拒绝并列出冲突子节点 |
| 删除有子机构 | 「该机构下存在子机构，请先删除子机构」 |
| 删除有用户引用 | 「该机构下存在用户（主机构或可登录机构），请先调整用户归属」 |
| 手机/座机格式 | 「请输入正确的手机号或座机号」 |
| 备注长度 | 「备注不能超过 500 字」 |
| 是否末端 | 仅网点可置是；其它类型传 true 返回「仅网点可标记为末端机构」，且保存时自动清空 |
| 机构性质必填 | 未传或不在 1/2/3 时返回「请选择机构性质（自营/加盟/合作）」 |
| 总部机构性质 | 内置总部固定自营，传 2/3 返回「内置总部的机构性质固定为自营，不可修改」 |

## 6. API 契约

| 前端方法 | 后端接口 | 入参 | 返回 |
|---|---|---|---|
| `getDeptTree()` | `GET /api/v1/system/depts/tree` | 无（全量，含禁用） | `DeptNode[]` |
| `getDeptPage(query)` | `GET /api/v1/system/depts/page` | `DeptQuery`（见第 5 节） | `{ records: DeptRow[], total: number }` |
| `getDeptDetail(id)` | `GET /api/v1/system/depts/{id}` | id | `DeptNode` |
| `createDept(data)` | `POST /api/v1/system/depts` | `DeptSavePayload` | `{ id }` |
| `updateDept(id, data)` | `PUT /api/v1/system/depts/{id}` | id + payload | `void` |
| `deleteDept(id)` | `DELETE /api/v1/system/depts/{id}` | id | `void` |
| `getDeptOptions()` | `GET /api/v1/system/depts/options` | 可选 `type` 过滤 | 精简树 |
| `sortDepts(ids)` | `PUT /api/v1/system/depts/sort` | `number[]` | `void`（二期拖拽预留） |

```ts
type DeptType = 1 | 2 | 3 | 4 | 5

interface DeptNode {
  id: number
  parentId: number
  deptName: string
  deptCode: string
  deptType: DeptType
  deptNature: 1 | 2 | 3
  isLeaf: boolean
  allowShip: boolean
  allowArrival: boolean
  allowPrepaidUnpaid: boolean
  allowCollectUnpaidSign: boolean
  leader?: string
  phone?: string
  address?: string
  sortOrder: number
  status: boolean
  remark?: string
  updateTime?: string
  children?: DeptNode[]
}
```

- 授权 Tab 与基础信息共用 `PUT/POST`，不做独立授权接口；
- `/options` 支持按类型过滤，供后续用户/角色的机构选择器使用；
- 权限点不变：`system:dept:list/add/edit/remove`。

## 8. 父子允许矩阵（五类）

线路已从机构树移除，线路由“路由管理”定义，不在 `sys_dept` 建节点。

| 父 \ 子 | 1 总部 | 2 公司 | 3 部门 | 4 分拨中心 | 5 网点 |
|---|---|---|---|---|---|
| 1 总部 | — | ✓ | ✓ | ✓ | — |
| 2 公司 | — | ✓（子公司） | ✓ | ✓ | ✓ |
| 3 部门 | — | — | ✓（子部门） | — | — |
