## 4. 筛选形态

### 4.1 统一规则（不新造控件）

| 控件 | 规则 |
|---|---|
| text 单模式 | 模糊匹配（`like`），空值不产生条件；不可切换模式 |
| text 多模式 | 六模式：等于 / 不等于 / 模糊 / 左匹配 / 右匹配 / 批量；**默认模糊**；批量上限 500，超限提示不静默截断（复用 `utils/textFilter.ts` 的 `TextMatchMode`，与后端 `TextFilterMode` 同口径） |
| select 单选 | 下拉单选，默认空（全部）；用于网点类 |
| select 多选 | 下拉多选，默认空（全部）；枚举类默认不过滤 |
| daterange | 固定日期区间，默认近 30 天？→ **默认空（全部）**，快捷项：今天/近 7 天/近 30 天/本月；列设置只读显示"固定按日期区间查询" |
| numberrange | 最小/最大两格，默认空；金额按元、重量 3 位小数 |

## 5. 默认排序与分页

| 项 | 结论 |
|---|---|
| 默认排序 | `create_time DESC`，第二排序键 `waybill_no DESC`（稳定分页，避免同一秒多条时翻页重复/漏行） |
| 可排序字段 | 除序号、操作外全部；服务端排序；枚举按码值、金额/数量按数值、日期按时间 |
| 默认每页 | **20**（D7）；可选 20 / 50 / 100 |
| 分页位置 | 工具条右侧（v1.14 定稿） |
| 合计口径 | 当前筛选条件下**全部数据**，后端与列表同一查询返回 |
| 稳定性 | 排序键不足时始终追加 `id DESC` 兜底，禁止不确定顺序 |

## 6. 操作列与行操作

列宽 160，`fixed=right`，居中；按钮顺序：`详情`、`子单(n)`（仅有子单）、`作废`。编辑本期不开放（D4）、打印不做（D10）。

| 按钮 | 显示条件 | 权限 | 说明 |
|---|---|---|---|
| 详情 | 始终 | `operation:waybill:query` + 数据权限可读 | 跳转详情页 `/operation/waybill/:id`（见第 7 节） |
| 子单(n) | `is_child=0` 且存在有效子单 | 同上 | 打开子单清单弹窗；n 为有效子单数；运单号点击同入口 |
| 编辑 | 本期不显示（D4） | — | 若后续开放，建议仅费用/联系人，且状态=20 |
| 作废 | `status=20` | `operation:waybill:void` + 写权限 + 管理员及以上（D5） | 二次确认 + 必填原因；写 `biz_waybill_log(action_type=4)` 与前后快照 |
| 打印 | 本期不显示（D10） | — | 二期随打印模板 |
| 删除 | 不提供 | — | 业务单据只作废不物理删除 |

- 无权限按钮**置灰并给 tooltip 原因**，不隐藏（v1.14 3.2.4）。
- 越权访问详情：后端返回 `403 无权访问该运单`，不泄露记录是否存在。

## 7. 运单详情页（独立页，开单页只读副本）

### 7.1 承载与信息架构

- 路由：`/operation/waybill/:id`，**独立页**（D3 已定），撑满内容区，不是抽屉。
- 布局严格对齐开单页 `views/operation/create/index.vue`：同一套 `section.card`、`grid four/two`、`fee-grid`、`hub-tags`、`sec-title`，分区与字段顺序与开单页一致，**不另起排版**。
- 全部控件只读：`el-input disabled` / `el-input-number disabled` / `el-radio-group disabled`，灰底、不可编辑；不显示必填红星、"标准 —"、校验红底；枚举以中文文本呈现。
- 结构：顶部标识条（sticky）→ Tab 栏（sticky）→ 内容区（随 tab 切换）→ 底部操作条。

### 7.2 顶部标识条（D11 待确认）

- 第一行：运单号（大号、可复制）+ 母/子徽标（母单带子单数）+ 状态标签 + 运单标签组（外转 / 回单 / 等通知 / 代收 / 大车直送）。
- 第二行：业务类型 · 开单网点 · 开单员 · 开单时间 · 关联单号 · 来源预开单号 · 目的地全称 · 运达网点。
- 右侧：`复制单号`、`返回列表`；`作废` 在底部操作条（权限与状态条件同列表）。

### 7.3 Tab 栏

| Tab | 本轮 | 内容 |
|---|---|---|
| 运单详情 | **实现** | 开单页只读副本（见 7.4） |
| 运输轨迹 | 占位 | 空态：`运输轨迹将在下一阶段开放`（数据来源见 7.6） |
| 改单信息 | 占位 | 空态：`改单记录将在下一阶段开放` |
| 核销信息 | 占位 | 空态：`签收 / 回单核销将在下一阶段开放` |
| 回单信息 | 占位 | 空态：`回单签收信息将在下一阶段开放` |
| 签收信息 | 占位 | 空态：`签收人、签收时间与凭证将在下一阶段开放` |

- 占位 tab 统一渲染「图标 + 一句说明」的空态，禁止白屏或空白表格；可点击切换，不请求接口、不报错。

### 7.5 开单页与详情页的复用方式（取舍）

- **选用：共享字段分区配置 + 独立只读渲染组件**
  - 新增 `views/operation/waybill/fieldGroups.ts`：定义分区（基本信息 / 目的地线路 / 发货方 / 收货方 / 货物 / 费用项 / 支付与配送 / 代收款）、字段 key、label、栅格跨度、格式化器（金额、枚举、日期、银行卡脱敏、空值 `—`）。
  - 新增 `components/operation/WaybillReadonlyForm.vue`：按配置渲染只读控件，详情页仅传运单数据对象。
  - 开单页本期**不改模板结构**，但 label 与字段顺序从同一份配置常量取值（改文案只改一处）；后续版本再让开单页按配置生成表单。
- **不选：同一表单组件加 `readonly` 开关**。开单页含大量联动（支付分摊、送货费必填、路由服务能力、候选弹窗），readonly 分支会侵入校验与联动逻辑，回归面大，且容易把编辑态行为带进详情页。
- 代价与约束：短期内开单页仍是手写模板，靠"同一配置导出 label/顺序"保证唯一来源；评审时校验两处一致，后续再做表单反哺。

### 7.6 运输轨迹数据源（本轮不实现）

- 现有 `biz_waybill_route_node` 是**路由快照**：`seq`、`route_scope`（1 干线路由段 / 2 外转段）、`from/to` 机构或区划、`route_code`、`route_category`（短驳/干线）、`warehouse_area`、`carrier`、`transit_hours`、`mileage`。
- 轨迹 tab 未来分两层：**计划分段**取 `route_node`；**实际节点**（装车、发车、到达、签收）需新表 `biz_waybill_track`（运单 id、节点类型、发生时间、操作人、机构、地点、备注），本方案不建表、不提供接口。
- 本轮仅占位空态。

## 10. 数据权限

| 档位 | 运单列表可见 | 详情/作废 |
|---|---|---|
| 1 全部 | 全部运单 | 可读；作废需 `operation:waybill:void` |
| 3 本机构 | `dept_id = 当前机构` | 同左 |
| 4 本机构及以下（默认） | `dept_id IN (当前机构 + 子孙机构)` | 同左 |
| 5 仅本人 | `create_by = 当前用户` | 同左 |

- 越权详情/作废：`403 无权访问该运单`；列表静默按档位过滤，不提示"有多少条被隐藏"。
- 车型/机构切换后：清空筛选、分页、选中行，重新请求；不缓存旧机构结果。
- 导出与合计同口径，不绕过权限。
- 拦截器需覆盖 `biz_waybill`、`biz_waybill_route_node`、`biz_waybill_goods`、`biz_waybill_log`；`biz_waybill_no_seq` 已豁免登记。
